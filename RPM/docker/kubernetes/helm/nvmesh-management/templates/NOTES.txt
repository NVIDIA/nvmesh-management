1. NVMesh Management WebUI:

   {{- else -}}

To get the URL for the NVMesh Management WebUI please run the following commands:

EXTERNAL_IP=$(kubectl get -n {{ .Release.Namespace }} service nvmesh-management-gui --no-headers | awk '{ print $4 }')
echo {{ if .Values.config.useSSL }}https{{ else }}http{{ end }}://$EXTERNAL_IP:{{.Values.guiService.port}}/

{{- end }}


2. NVMesh Host Configuration:
-----------------------------
{{ if .Values.ingressType -}}

Make sure to configure in /etc/nvmesh/nvmesh.conf MANAGEMENT_SERVERS="nvmesh-management-0:443,nvmesh-management-1:443,nvmesh-management-2:443"

NOTE: Make sure the host resolves each of the hostnames to your ingress entryPoint IP (Your ingress controller service externalIP)
This could be done by adding the following line to you /etc/hosts on each host, replace INGRESS_IP with your ingress externalIP:

<INGRESS IP> {{ range $replicaIndex := until (.Values.replicas|int) -}}nvmesh-management-{{- $replicaIndex }} {{ end }}
{{- range $replicaIndex := until (.Values.replicas|int) -}}
   {{- range $statIndex := until ($.Values.config.statisticsCores|int) }}nvmesh-management-{{- $replicaIndex -}}-{{- $statIndex }} {{ end }}
{{- end }}

{{- else if eq .Values.service.type "LoadBalancer" -}}

Make sure to configure on each NVMesh host's /etc/nvmesh/nvmesh.conf
MANAGEMENT_SERVERS="<IP1>:{{.Values.service.port}},<IP2>:{{.Values.service.port}},.."

Where <IP1>, <IP2> .. are each of your service externalIPs ({{.Values.service.externalIPs}})

{{- else -}}

Make sure to configure in /etc/nvmesh/nvmesh.conf MANAGEMENT_SERVERS="nvmesh-management-0:<port>,nvmesh-management-1:<port>,nvmesh-management-2:<port>"

NOTE: Each nvmesh-management-<n>:<port> should resolve to the corresponding entryPoint for the corresponding service (i.e nvmesh-management-svc-0, nvmesh-management-svc-1, ..)

{{- end }}
